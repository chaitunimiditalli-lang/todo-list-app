# To-Do List App

A client-side To-Do List application built using HTML, CSS, and JavaScript.

## Features

- Create Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Completed
- Filter Tasks (All, Active, Completed)
- Local Storage Persistence
- Dynamic DOM Manipulation
- Event Delegation

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API
